# ADR：依赖图复用与报告消费校验

- 编号：E11-A-39；日期：2026-11-14；小组：A11。
- 实现者：231880027 / tongqianpolan，来源为 PR #41 及其个人实验报告。
- 整理与设计复核：241880439 / MaxizYB，组长，AI 辅助。本记录由组长归纳并复核，不冒充实现者另行签署的文件。

## 问题与备选

仅比较增量与全量报告可能共同漏报，需独立预期；报告被篡改或属于旧提交时，不得被下游消费。备选为只检查两种输出是否相等、重新实现一套校验器，或复用公共校验并增加固定集合和真实调用断言。

## 采用方案与原因

采用成员现有实现：固定断言完整 actual、declared、findings 及差量；无变化和函数体变化时监测真实 gcc -MM 调用，验证依赖图复用；共享头文件新增 include 后按既有全局依赖键保守刷新两个目标。图复用不等于 Make 无需重新编译。

个人报告消费者依次调用公共 load_artifact 和 check_envelope，先验证内容 SHA256，再核对版本、产物类型、上游状态和目标 commit，保留原异常码。旧报告和错提交基线返回 STALE_REPORT，字节变化返回 ARTIFACT_HASH_MISMATCH。不扩大这些测试对任意损坏缓存或额外 configuration_id 语义的覆盖声明。

## 输入输出与兼容性

编排封装为 e11e12-1，scan 内层为 e8e10-1；full-check 属于 base，incremental-check 属于 target。任务保留 job_id、trace_id、configuration_id、产物 URI 和哈希。个人 load_tests 将三项 scan 测试挂入既有入口，另增四项消费测试，不改变公共命令、契约和他人测试。
