# ADR：保留成员提交并区分参考回放与跨组验收

- 日期/作者：2026-11-14，241880439 / MaxizYB，A11。
- 问题：成员分支均基于未合并的公共准备提交，且 AI_USAGE 并行追加冲突；组长还需准备 E12 服务及可核验的交付证据。
- 采用方案：审核后以 merge commit 合入 #40，保留公共基础来源；在独立收尾分支整合 #41，保留两人的 AI 记录。使用同摘要镜像源解决构建元数据访问失败，在新服务器克隆运行，保存成功与失败日志。
- 接口决策：沿用课程共享 e11e12-1 编排 API，保留 E2 1.0.0 组件契约；客户端保存真实提交/轮询/冲突与下载，并验证清单、响应头和文件 SHA256 一致。
- 备选：重置成员分支、放宽 main 保护、将组长同机结果称为 B11 联调；均不采用。
- 兼容性：新增镜像/样例命名参数为可选项，原命令仍可用；课程样例、真实项目、B11 确认分别验收。
- 测试：在公共与成员测试之上增加客户端下载成功、字节篡改拒绝、非法 URI 拒绝三项；运行摘要记录云端实际结果。
