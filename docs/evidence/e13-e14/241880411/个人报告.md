## E14 四服务独立核查

使用 H1 和 A11 实际交接项目分别核查。A11 交接包的候选字节及请求中的 base、target 与本次实测一致，分别是 `5b431fcc656804434db59f4452f046ef284e6eb4` 和 `c2301112968b4cf185a94449e5dbc85764f4a2df`。

- 四服务均健康。每轮完成 16 项 HTTP 检查，覆盖健康页面 200、未知路由 404、无效 JSON 和不允许的工作路径 422。被拒请求未生成输出目录。
- BuildChecker、EChecker、DRAFT、MDFixer 的正常和恢复日志均与各轮 job/trace 一致，处理次数依次为 3、1、1、1。0.01 秒受控超时只到达 DRAFT，返回 HTTP 422 / TIMEOUT，外层 `FAILED`，内层 `TIMED_OUT`。超时后检查到无残留构建客户端或该次构建镜像，下一轮使用新的 job、trace 和目录成功，失败结果字节保持原样。
- H1 初次和恢复各校验 183 个产物，A11 各校验 174 个。四角色通过同一镜像启动，每个容器限制为 1 CPU、768 MiB、128 PIDs，启用 no-new-privileges，均未使用 privileged。只有 DRAFT 挂 Docker socket，只有 BuildChecker 加 SYS_PTRACE。宿主发布地址均为 `127.0.0.1`，端口 18081–18084。
